Run it yourself

The strategy library on this site is real code in the strategies/ folder. Backtest it locally, then run it through a self-hosted OpenAlgo instance.

Backtest

Needs Python with pandas and numpy.

Demo datapython backtest/backtest.py --demo --strategy ema_crossover
Your CSV--csv data.csv
Broker history--openalgo SYMBOL EXCHANGE 5m START END

Paper trade, then go live

Run openalgo/setup.sh to install OpenAlgo, turn on Analyzer Mode, set your API key, and start the runner. It only prints orders until you change DRY_RUN.

Runnerstrategies/live_runner.py
Shared logicstrategies/signals.py
Default modeDry run

These are templates, not advice or promised returns. Test on real data with costs, and verify OpenAlgo call signatures in its docs before relying on them.
